## STEP 1: Create Google Ads Account (5 minutes)

1. Go to: **https://ads.google.com**
2. Click: **"Start now"** or **"Sign in"**
3. Use: **director@ay-toiture.fr** Google account
4. Set: **Time zone** to Europe/Paris
5. Set: **Currency** to EUR (€)

---

## STEP 2: Switch to Expert Mode (Critical!)

Google will try to use "Smart Mode" (limited control). **You need Expert Mode.**

1. When asked "What's your advertising goal?"
2. Click: **"Switch to Expert Mode"** (small text link)
3. Select: **"Leads"** as campaign objective
4. Select: **"Website"** or **"Phone calls"**

## STEP 5: Conversion Tracking (CRITICAL!)

You MUST track which ads generate phone calls.

### **1. Phone Call Tracking**

**From Google Ads dashboard:**
1. Click: **"Tools & Settings"** (wrench icon)
2. Click: **"Conversions"** under **"Measurement"**
3. Click: **"+"** button → **"Phone calls"**
4. Name: `Calls from Google Ads`
5. Value: Leave blank for now
6. Count: **"Every"** phone call
7. Click: **"Done"** and **"Save"**

**Importing Conversions:**
1. After setup, copy conversion ID
2. Add to your website (if using Google forwarding number)
3. OR manually track: Ask every caller "How did you find us?"

**Simple Manual Tracking:**
When customers call, ask:
*"Comment avez-vous entendu parler de nous ?"*
- Google Ads
- Google Maps
- Facebook
- Word of mouth
- Other

Write this down! It tells you which ads work.

## 🎯 OPTIMIZATION TIPS

### **Week 1: Monitor & Adjust**

**Check daily for first week:**

**If NO calls:**
- Keywords might be wrong (check search terms)
- Ad copy not compelling (rewrite headlines)
- Bid too low (increase to €2.00)

**If calls BUT no jobs:**
- Check if calls are relevant (ask caller location)
- Keywords too broad (add more negative keywords)
- Ad message not clear (mention specific services)

**If lots of clicks BUT few calls:**
- Ad copy too generic (be more specific)
- Landing page not compelling (add urgency)
- Wrong audience (tighten location targeting)

### **Month 1-2: Optimize Winners**

**Identify Top Performers:**
1. Click: **"Keywords"** tab
2. Sort by: **"Conversions"** (calls)
3. **Pa**use keywords with no calls
4. Increase bids on keywords WITH calls

**Example:**
- "fuite toiture toulon" → 5 calls → INCREASE bid to €2.00
- "couvreur urgence" → 0 calls → PAUSE or lower bid

## 🚨 CRITICAL WARNINGS

### **DON'T:**
- ❌ Use "Smart Mode" (too limited control)
- ❌ Set max CPC too high (€5+ is too expensive)
- ❌ Target all of France (budget will waste)
- ❌ Ignore negative keywords (wastes money)
- ❌ Set ads to run 24/7 (you can't answer at night)

### **DO:**
- ✅ Use "Expert Mode" for full control
- ✅ Set bid limits (€1.50-2.00 max)
- ✅ Tight location targeting (Toulon area only)
- ✅ Add negative keywords weekly
- ✅ Only run ads when you can answer phone
