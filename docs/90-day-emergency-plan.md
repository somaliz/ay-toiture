## 🚨 RED FLAGS (Watch For These)

### **Warning Signs:**
- 🔴 **0 calls in Week 1** → Check phone number, ad targeting, keywords
- 🔴 **Calls BUT no jobs** → Wrong audience, ads misleading, phone etiquette issue
- 🔴 **CPC > €3.00** → Keywords too competitive, tighten location
- 🔴 **Quality score < 5/10** → Ad relevance issue, rewrite ad copy
- 🔴 **0 reviews in Month 1** → Not asking customers, make review process easier

### **If ANY red flag appears:**
1. **STOP** what you're doing
2. **ANALYZE** the data (why is this happening?)
3. **ADJUST** strategy (change keywords, ad copy, targeting)
4. **TEST** new approach for 3-7 days
5. **MEASURE** results
